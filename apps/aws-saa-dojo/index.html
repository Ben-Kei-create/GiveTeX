AWSTUDY SAA 設計道場

要件が変われば、答えも変わる。

AWSのサービスを、名前ではなく設計の条件から選べるように。AWSTUDY SAA 設計道場は、SAA-C03の出題範囲を参考にした日本語の学習アプリです。10問を1セットとして何度でも解け、要件が途中で変わる連問と、先輩エンジニアの講評で「何を取って何を捨てたか」を確かめられます。

学習の流れ

  • 「10問セットを始める」から、10問ずつ、何セットでも続けられます。
  • 一部の問題は、同じ案件に要件変更が入る連問です。同じ構成が、条件によって別の答えになることを体験できます。
  • 選択を確定すると、戻って選び直すことはできません。設計の後戻りのコストを、そのまま体験する作りです。
  • 確定後は、全選択肢の理由、先輩の講評、「取ったもの／捨てたもの」、AWS公式ドキュメントへのリンクを確認できます。
  • 間違えた問題は「差し戻し」として記録され、次のセット以降に混ざって出題されます。
  • 案件簿で、案件の進み具合と差し戻しの件数を確認できます。
  • 用語辞典で、AWSの用語（82語）を、3行ほどの解説で引けます。上の検索欄で探せます。

アプリの情報

対応iPhone／iOS 17以降・縦画面
言語日本語
料金無料・広告あり。アプリ内課金はありません。
学習内容全45案件・70問（うち25案件は要件変更つきの連問）。安全・可用性・性能・コストの4分野。
広告セットの結果画面から「もう1セット」または「終わる」を選ぶ際に、全画面広告が表示される場合があります。出題中には表示しません。
通信クイズはオフラインで利用できます。公式資料のリンクと広告には通信が必要です。
データログイン不要。案件簿（済の案件、差し戻し、終えたセット数）は端末内にだけ保存し、運営者のサーバーへ送信しません。アプリを削除すると消えます。
配信App Store（準備中）

公式試験との違い

本アプリはAWS非公式の学習アプリです。Amazon Web Servicesによる提供・承認を受けたものではありません。公式試験問題を転載しておらず、問題はすべてオリジナルです。公式試験の問題数・形式・採点方式を再現するものではなく、試験範囲すべてを網羅せず、合格を保証しません。AWSおよび各サービス名は各権利者の商標です。
