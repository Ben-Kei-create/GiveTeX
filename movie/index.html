    評価

    ルール（みんなで管理しています）
    • 名前は全員「名無しの映画好き」。ID は1日ごとに変わります。
    • 3人から「通報」されると、自動で見えなくなります。
    • 自分の書きこみは、同じブラウザからなら「削除」できます。
    • 連続投稿・同じ文の投稿・リンク・個人情報・ひどいことばは、機械ではじきます。
    • 書きこみは新しい順に1000件まで残ります。

    iPhone アプリ 開発中

    C-Log for iPhone

    2022〜2023年につくった映画レビューサイト「C-Log（CINEMA-LOG）」を、iPhone アプリとしてつくり直しています。映画を観たらチェックひとつで記録して、感想を残せる、電子版の映画ノートです。

    • さがす作品名から映画を検索（TMDb）
    • Impression観た映画の感想を、星と一緒に残す
    • Web 版このページ。話題の映画と、みんなの匿名の感想ノート
    • マイノート自分だけの鑑賞記録
    • ウォームアップ映画トリビアで、観る前にひと盛り上がり
    C-Log Web — GiveTex の映画ブース
