■ 2026/11/15(日)　[Muse]

Muse の現在地と、これからの順番

11/10〜15 に考えた Muse の設計を、ここで一度まとめました。いまは設計と指示書ができた段階で、新しい機能の実装はこれからです。

  • できているもの：これまでの作業支援の機能と、それを管理するアプリ
  • 今回つくった設計：Muse Worker 2.0 のアップデート方針、下書き → 本人リライトの書き方、案件管理・作業ログ・収益分析、Muse Seller の指示書と専用アプリの構想、アプリを分けて将来つなぐ方針

これからの順番：

  1. 今ある Muse の受注まわりの機能をひろげる
  2. 下書き・リライト・修正履歴の保存をつくる
  3. Muse Seller の専用アプリをつくる
  4. 最初の商品をつくって、売れるか確かめる
  5. 必要になったら、事業ごとの収益をつなげる

基本の考え方は、今ある機能はこわさずに、受注の「すぐ入る収入」と、商品販売の「積み上がる収入」を並行して育てること。

■ 2026/11/15(日)　[Muse]

アプリは用途ごとに分ける。いずれ「Muse Manager」でまとめる

受注用（Worker）、販売用（Seller）、それとは別のスペースアプリは、それぞれ独立したアプリとしてつくることにしました。

  • Seller には専用の管理アプリを新しくつくる。画面は、商品管理・販売状況・収益分析・AI の作業キュー
  • いずれ受注と販売の収益をつなげる「Muse Manager」も考える
  • ただし当面は、それぞれのアプリを完成させるのが先。つなぐのは必要になってから
■ 2026/11/15(日)　[Muse]

「仕事をする AI」と「売る AI」を分ける ― Muse Seller の構想

頼まれた仕事をこなす Muse とは別に、自分の商品を売る役として「Muse Seller」を考えました。

  • Seller の担当：市場調査、商品の企画、制作の手伝い、販売の準備、売上の分析
  • 売るもの：デジタル商品、電子書籍、アプリ、テンプレートなど
  • 一度つくった商品が売れ続ける「積み上がる」収益を大事にする
■ 2026/11/15(日)　[Muse]

Muse Worker 2.0 の設計と、アップデート指示書

今の Muse を「作業の手伝い」から「収益につながる仕事を手伝う AI」に育てるため、Muse Worker 2.0 を設計しました。

  • 案件さがし → もうかるかの評価 → 作業 → 品質チェック → 収益の分析、までを受け持つ
  • 案件は、報酬だけでなく手数料と作業時間もふくめた「実質の時給」で比べる
  • 文章の校正、リサーチ、資料づくり、データ整理などにも対応する
  • 作業の記録をためて、次の仕事に使い回す

文章の仕事は、Muse が構成と初稿を先につくり、最後に自分がリライトして仕上げる形に。初稿と完成稿の差を保存して、直し方のくせから自分の文体を学ばせ、次の下書きをよくしていきます。

これらは「Muse 2.0 アップデート指示書」にまとめました。新しく作り直すのではなく、今ある画面・記録・データはそのまま残して機能を足す方針です。段階ごとの実装計画と、完成の条件も決めました。

■ 2026/10/17(土)　[ドパリカ！]

本番用の山の背景10枚を制作。10枚で1本の巨大な地層世界に

ドパリカ！の本番用の山の背景を、画像生成で10枚つくりました。最初の版は「地中なのに突然空がある」「上下の地層がつながらない」などの問題があったので、方針から作り直しました。

  • 10枚を縦に並べると、1本の巨大な世界になる（ファイルは10枚のまま）
  • 上端と下端の岩の質・色・地層を、次の画像へ自然につなげる
  • 空が見えるのは最上部だけ。地下に入ったら空は出さない
  • 表土 → 砂礫 → 地層 → 化石 → 褶曲 → 断層 → 火成岩 → 溶岩 → 巨大岩盤 と進んでいく
  • スマホの横幅に合わせて、できるだけ縦長に

これでドパリカ！は、ただの理科の4択アプリではなく、「問題を解く → XP が増える → 背景の世界を進む → 新しい問題を集める」という3本柱が固まりました。最初のリリースは「山・地層／Lv.1〜30／2択」。次は、背景10枚の差し替え → 縦の世界の実装確認 → レビュー・QA → 修正、と進めます。

■ 2026/10/17(土)　[ドパリカ！]

背景の進み方を作り直す（XP・レベルと連動）

最初は「1問正解 → 次の背景へ」という作りでした。でもこれだと、5問全問正解で5つ進み、次に始めるとレベルの位置に戻ってしまう問題が出てきました。そこで仕様を変更しました。

  • 背景の位置を、累積 XP・レベルと同期させる
  • 「本当に到達した位置」と「演出上の今の位置」を分けて持つ
  • 考えている間・不正解・時間切れでは、演出上の位置だけ後ろに下がる（XP は減らない）
  • 正解すると XP が増えて、本当の到達位置まで勢いよく上昇
  • 10枚の画像は「10問分」ではなく、Lv.1〜30を通して進む1本の地層世界としてあつかう

■ 2026/10/17(土)　[ドパリカ！]

画面と背景の演出を具体化。AI 3人体制で開発スタート

問題パネルの後ろで、背景が縦にスクロールする方式にしました。参考にしたのは、アトラクションの「垂直に加速する感じ」。ただし怖い演出は使いません。

  • 正解すると、ゆっくり → 急加速 → 減速、と上昇
  • 不正解だと背景が後退
  • 考えている間も、時間とともに少しずつ後退（制限時間つき）
  • 山＝地層、空＝大気圏から宇宙、海＝海面から深海。それぞれ長い縦の世界にする
  • 各ステージに10種類くらいの背景を用意する

開発の分担も決めました。ChatGPT＝仕様・設計・指示、Claude Code＝Swift／SwiftUI の実装、Codex＝レビュー・QA。さっそく仮の画像で、アプリアイコン・ホーム背景・山の背景10枚を組みこみました。

■ 2026/10/16(金)　[ドパリカ！]

ドパリカ！の基本の仕様を固めた

中学理科アプリの名前を「ドパリカ！」に決定。iPhone 専用・SwiftUI でつくります。ねらいは高校入試の「大問1」対策です。

  • Lv.1〜30＝山（2択）、Lv.31〜60＝空（3択）、Lv.61〜100＝海（4択）
  • レベルは「ステージ」ではなく、自分の累積 XP のレベル。自分では選べない
  • 1セット5問。復習でも XP がもらえる
  • 前のレベルで間違えた問題を優先して出す。間違いがなくても、最低2問は復習を混ぜる
  • 問題の総数は見せない
  • 最初のリリースは Lv.1〜30（山）まで
  • Lv.31以降は、山のランダム復習もできる（XP は半分）
  • 「問題蒐集」：山・空・海のタブ。まだ出会っていない問題は「????」、一度解いた問題は問題文と答えを見られる
