2026年11月

■ 2026/11/15(日)　[ブース]

ブースを5つ一気に開設

「ゲーム」「美術館」「ラーメン」「映画（C-Log Web）」、それからサイトの裏側の「ブックマーク」ブースを作りました。ゲームはコインあつめ、ラーメンはスクロールで麺がのびます。中身はこれから少しずつ。note ブースには TALES の連載『島の灯台と猫』も並べました。

■ 2026/11/15(日)　[スタンプ]

スタンプブースをつくりました

つくった LINE スタンプを紹介する「スタンプブース」を作りました。グループトークの中に入ったような画面で、スタンプを選んで送ってためせます（送ったものは画面の中だけで、どこにも送信されません）。heatshimmer の名前で出している18セット・248種類を並べました。

■ 2026/11/15(日)　[note]

note の過去記事を349本、まるごと移植

2021年から note に書いてきた記事349本を、note ブースに移しました。年ごとの目次、タグ、検索から読めます。Java の勉強記録などはコードも読みやすく整えました。有料記事（30本）は無料部分だけをのせて、続きは note へご案内しています。

■ 2026/11/15(日)　[note]

note ブースをはじめました

NingentteWinner の名前で note に5年ほど書いてきた創作を、こちらにも置いていくための「note ブース」を作りました。とにかく読みやすさ優先で、背景（白・セピア・黒）、文字の大きさ、明朝／ゴシックを切り替えられます。記事はこれから少しずつ移していきます。

■ 2026/11/15(日)　[アプリ]

アプリのページを、すっきりしたデザインに

アプリのページだけ、白と黒を切り替えられるシンプルなデザインにしました。各アプリのサポート・プライバシーのページも同じ見た目です。

■ 2026/11/15(日)　[どろん]

Cサークルの新企画「十人奇談」、準備中

オカルトブース「どろん」のCサークルで、「十人奇談」という企画を考えています。前半・後半の札と、「怪談」「奇談」「雑談」の題名カードを作りました。くわしい内容は決まりしだい、ここと Cサークルのページでお知らせします。

十人奇談 前半・後半の札怪談・奇談・雑談 の題名カード
■ 2026/11/15(日)　[サイト]

ホームページを90年代風にリニューアル！

インターネットが始まったころの「ホームページ」の空気を目指して、まるごと作り直しました。テーブルでレイアウトして、マーキーが流れて、アクセスカウンターが回る、あの感じです。どろんのロゴも3種類になりました。

■ 2026/11/15(日)　[サイト]

Kindle本は「ドパ読！」に。オカルトブース「どろん」も開設

Kindle電子書籍のコーナーを「ドパ読！」と名付け、「30秒で読む」シリーズ全96冊を6ジャンルの本棚に。あわせて、座談会「relics」・心霊スポット巡り「霊界案内所」・巡って発表する「Cサークル」の記録を置くオカルトブース「どろん」を作りました。
