このサイトについて

教育 × IT で、学びをつくって届ける。

GiveTex（ギブテックス）とは

GiveTexは「Give（与える）× Education × Technology」を掛け合わせた造語です。教育とITをかけ合わせて、「学び」を形にして届けることをテーマにしています。

やっていること

📱 アプリ開発漢検・化学・物理・AWS・Linuxなど、学べるiPhone / Macアプリ
📚 Kindle出版生成AIを相棒に企画・執筆した電子書籍
📝 開発日記つくる過程とリリースの記録
💡 記事AI・学習ツールの比較とガイド

運営者プロフィール

  • テーマ：教育 × IT
  • 分野：理科（物理・化学・生物・地学）、資格学習、Webアプリ / iOS・macOSアプリ開発、AIを活用した出版
  • 使用技術：Swift / SwiftUI / Next.js / React / Supabase / Flutter / 生成AI
  • 実績：App Storeで学習アプリなど7本を公開（2026年11月時点）、ほか多数を開発中
