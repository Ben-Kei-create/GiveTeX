# ミニゲーム4本のソース（GiveTex）

`index.html` をブラウザで開くと遊べます。ゲームの中身は、ぜんぶ `minigames.js` の1ファイルです。

- ブロックおとし ／ うちゅうげきたい ／ クレーンゲーム ／ じゃんけんポン（メダルゲーム風）
- 操作：画面の下のボタン。パソコンは、ゲーム画面をクリックしてから ← → ↑ ↓ と スペース（または Z）

## 読み方

4つのゲームは、同じ形の「部品」になっています。

```js
var block = {
  name: 'ブロックおとし', key: 'block', help: '…',
  reset: function () { … },   // はじめの状態にする
  step:  function (dt) { … }, // 時間を進める（dt は前のコマからのミリ秒）
  input: function (k) { … },  // ボタンが押された（'left' 'right' 'up' 'down' 'a'）
  draw:  function () { … }    // 画面をかく。下に出す文字（スコアなど）を返す
};
```

いちばん下の `frame` が「ゲームループ」です。1秒に約60回、`step` → `draw` をくり返します。
画面は 160×240 の小さなキャンバスに、四角（`fillRect`）と文字だけでかいています。

音は `TUNES` に入っています。数字は MIDI の音の番号（60 が「ド」、69 が「ラ＝440Hz」）、`0` は休み、`-1` は前の音をのばす、です。

## やってみよう

1. `block` の `COL`（色）を変えて、自分の色のブロックにしよう。
2. `space` の `life = 3` を 5 にしてみよう。どこを変えればいい？
3. `crane` で、つかめる確率（`Math.random() < .75`）を変えると、むずかしさはどうなる？
4. `janken` の `RING`（ルーレットの数字）に 50 を入れてみよう。メダルは増えやすくなる？ へりやすくなる？
5. `TUNES` の `bpm` を倍にすると、曲はどう聞こえる？ 自分のメロディも入れてみよう。
6. 同じ形（`reset` `step` `input` `draw`）で、5本目のゲームを作って `GAMES` に足してみよう。
