# ファミコン風の音の出し方（GiveTex）

ブラウザだけで音を作る見本です。音声ファイルは1つも使っていません。
`index.html` を開いて、ボタンを押してください（音が出ます。音量に注意）。プログラムは `sound.js` です。

## 音のしくみ

- **音の高さ＝周波数（Hz）**：1秒間に何回ふるえるか。「ラ」は 440Hz。2倍の 880Hz にすると、1オクターブ高い「ラ」になります。
  - 半音1つ上がるごとに、周波数は約 1.0595 倍（2 の 12 乗根）。`sound.js` の `hz()` がその計算です。
- **音色＝波形**：`square`（四角い波）はピコピコしたゲームの音、`triangle`（三角の波）はやわらかい低音、`sine`（サイン波）は澄んだ音、`sawtooth`（のこぎり波）はとがった音。
- **音の大きさの変化（エンベロープ）**：出だしを速く大きくして、だんだん小さくすると、鍵盤をたたいたような音になります。`note()` の `gain` のところです。
- **雑音（ノイズ）**：でたらめな数をならべると「ザッ」という音になります。クリック音やドラムに使います。

## 曲のデータ

```js
lead: [69, 0, 72, 74, 76, -1, 74, 72]
```

数字は MIDI の音の番号です（60＝ド、62＝レ、64＝ミ、65＝ファ、67＝ソ、69＝ラ、71＝シ、72＝高いド）。
`0` は休み、`-1` は前の音をのばします。`bpm` は1分間の拍の数（速さ）です。

## やってみよう

1. ページの「周波数」のつまみを動かして、440Hz と 880Hz を聞きくらべよう。
2. 同じ高さで、波形だけを変えて聞きくらべよう。どれがいちばん「ゲームっぽい」？
3. `sound.js` の `SONGS` に、「ドレミファソラシド」を入れて鳴らそう。
4. `bpm` を半分・2倍にすると、どう聞こえる？
5. 「かえるのうた」のように、同じメロディを少しおくらせて重ねる（輪唱）には、どう書けばいい？
6. 効果音を1つ作ろう（例：ジャンプ＝低い音から高い音へ、すばやく変える）。
