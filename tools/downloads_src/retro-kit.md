# 90年代ホームページの作り方キット（GiveTex）

1990年代おわり〜2000年ごろの「個人のホームページ」の見た目を、いまの HTML と CSS で作るための見本です。
`index.html` をブラウザで開いてください。

## 入っているもの

| ファイル | なかみ |
|---|---|
| `index.html` | 見本のページ。ウインドウ、流れる文字、表、カウンター、おみくじ、バナー |
| `retro.css` | GiveTex で実際に使っているスタイル（Windows 95 風のウインドウやボタン） |
| `kit.js` | ウインドウのボタン（たたむ・もどす・とじる）、タイトルをつかんで動かす、カウンター、おみくじ |
| `img/` | 星空の背景、NEW! マーク、工事中、88×31 のバナー |
| `make_banner.py` | 88×31 の点滅バナーを作るプログラム（Python と Pillow が必要） |

## 「それっぽさ」のひみつ

- **立体的なボタンとウインドウ**：線を引くかわりに、内がわの影（`box-shadow: inset …`）を4本重ねています。左上を白、右下を黒にすると出っぱって見え、反対にするとへこんで見えます。`retro.css` の `.win` と `.r-btn` を見てください。
- **青いタイトルバー**：`linear-gradient(90deg, #000080, #1084d0)`。
- **流れる文字**：むかしの `<marquee>` タグ。いまも多くのブラウザで動きます。
- **表でレイアウト**：むかしは `<table>` でページを左右に分けていました。
- **88×31 のバナー**：ホームページどうしでリンクしあうための、小さな看板。大きさが決まっていたので、ならべるときれいにそろいます。
- **アクセスカウンター**：見本では、このブラウザの中だけで数えています（`localStorage`）。本物は、サーバーが数を覚えます。

## やってみよう

1. `index.html` の文字を、自分の自己紹介に書きかえよう。
2. ウインドウをもう1つ足そう（`<div class="win">` から `</div>` までをコピー）。
3. `retro.css` の `.win-t` の色を変えて、自分の色のタイトルバーにしよう。
4. `box-shadow` の白と黒を入れかえると、ボタンはどう見える？
5. `kit.js` のおみくじに、新しい運勢を足そう。
6. `make_banner.py` の `SPEC` に1行足して、自分のバナーを作ろう。
