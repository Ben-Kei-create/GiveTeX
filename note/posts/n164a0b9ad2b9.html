Javaの基礎知識

Javaのプログラミング開発は
・ソースコードの作成
・コンパイル
・実行
で成り立ちます。

ソースコードの作成
public class ~のような記述で、Javaの文法で書いたもの。

コンパイル
ソースコードは、そのままでは実行できないので、ソースファイルをクラスファイルに書き換えます。この時の拡張子は、.classを使うことになっています。この中には、機械が読みやすくなったbyte code（バイトコード）と呼ばれるものが詰まっています。
このバイトコードは、1と0(2進数)でできています。

実行
インタプリタというソフトウェアに対して、このバイトコードの変換と実行をお願いする。インタプリタは、内部にJava Virtual Machineという仕組みがあります。
略すとJVMと呼ばれますが、これがクラスファイル内のbyte code（バイトコード）を読み取ってくれます。JVMがバイトコードを読み取りながらコンピュータの中央処理装置であるCPUがわかりやすいようにマシン語に翻訳してくれます。同時に、CPUは処理を実行させてくれます。

結果的に、このようにして実行することができるようになります。

Javaの開発環境の整備

バイトコードに変換、そしてCPUがわかりやすいようにマシン語に変換されます。よって、バイトコードに変換してくれるコンパイラとマシン語に変換してくれるJVMは自分のコンピュータにダウンロードとインストールする必要があります。

変数宣言の文

変数とは、データを格納（しまう）ためにコンピュータ内部に準備する箱のようなものです。
この箱を用意する理由は、この変数を準備することで文字列や数値などをとても簡単に扱うことができたり、効率的に開発をすることができるようになります。

変数は、コンピュータの中のメモリにある区画です。

public class Main {
  public static void main(String[] args) {
    System.out.println("変数を宣言してみる");
    int age = 29;
    System.out.println("私の年齢は" + age + "です。");
  }
}

型を指定した後、箱の名前を決めます。なるべく、箱の名前で中身に何が入っているかが分かるように書くべきです。

【続き】整数型の特徴を整理する

本文の途中で「整数型（byte, short, int, long）では、この型はどんな特徴があるのでしょうか。」と問いかけたままになっていたので、ここで整理します。

・byte：-128〜127まで、1バイト。とても小さい整数用。
・short：-32,768〜32,767まで、2バイト。byteより少し大きい整数用。
・int：約-21億〜約21億まで、4バイト。ふだんの整数はまずこれ。
・long：約-922京〜約922京まで、8バイト。とても大きな整数用。書くときは数字のあとに L を付けます。

選び方の目安はシンプルです。迷ったら int から始める。年齢や人数、点数のような身近な数は int で十分です。byte や short は、メモリを節約したい場面や、範囲がはっきり決まっている場面で使うものだと覚えておけば大丈夫です。

【まとめ】今回の①で学んだこと

・System.out.println で文字や計算結果を出力する
・"" で囲んだものはそのまま文字として出て、囲まない数式は計算される
・変数は「型 箱の名前;」で宣言して、データを入れる箱として使う
・プログラムは「ソースコードの作成→コンパイル→実行」の流れで動く
・メソッドの骨格と、読みやすいコードのためのインデントとコメント

占いのアプリや数あてゲーム、ごはんプログラムのように、出力・変数・条件分岐・繰り返しを組み合わせれば、もう小さなプログラムが作れます。①はここでいったん完結です。次に進むときは、実践編の練習問題で手を動かしながら、型とメソッドの使い方を確かめていくのがおすすめです。
