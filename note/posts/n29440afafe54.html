Gemini完成インストールコピペ

Gemini CLIで自走ゲームつくりかた

2025.07.10

Gemini CLIでゲームをつくるよ。

作り方①、②、③

①Gemini CLIをインストール

②geminiと打ってGemini CLIを立ち上げる

③以下をコピペ

#!/bin/bash

# ゲームのアイデアをここに書く
GAME_PROMPT="PythonとPygameで、プレイヤーがマウスで動く円を操作し、画面の端から迫ってくる四角を避けるゲームを作って。詳細は任せます。"

# ファイル名
FILENAME="my_game.py"

echo "🤖 Geminiにゲームのコード生成を依頼します..."

# Gemini CLIでコードを生成し、Pythonコードブロックだけを抽出してファイルに保存
gemini generate "$GAME_PROMPT" | awk '/```python/{flag=1; next}/```/{flag=0}flag' > $FILENAME

if [ ! -s $FILENAME ]; then
    echo "❌ コードの生成に失敗しました。"
    exit 1
fi

echo "✅ コードを $FILENAME に保存しました。"

# 依存ライブラリのインストール（Pygameが含まれているかチェック）
if grep -q "pygame" $FILENAME; then
    echo "🐍 Pygameをインストールします..."
    pip install pygame
fi

echo "🚀 ゲームを実行します！"
python $FILENAME

完成。
