class Echo{
  public static void main(String[] args){
    //コマンドラインの入力文字列を表示（for文）
    for(int i = 0; i < args.length; i++) {
      System.out.println(args[i]);
    }

うわ〜・・なるほど。

   for(int i = 0; i < args.length; i++) {

まず宣言としてint i = 0;
条件として、args.lengthにすると、要素数になる。
これはつまり、私がコマンドラインに書いた要素の数になる。
この要素数よりも少ない場合はその要素（文字列）を表示させる。

例えばaa bb ccと打った場合。
args.lengthは3だ。まずi=0から始まるので、i=0,1,2までの３つが出力されることになる。よって、条件式はi < args.lengthとするべきなのがわかった。
そして、その下の

      System.out.println(args[i]);

をした後に、i++;(インクリメント)をさせれば、i=0が1に変わり、1が２へと加算されていく。
そして、System.out・・・の部分も、引数にargs[i]とすることで、Strings args[]の配列からi=0から順に出力できるということなのか・・・すげー！！
納得。

よって、args[0]はaaだし、args[1]はbbだし、args[2]はccだ。
i=3になった時、args.length（要素数は3）となり、for文は機能しなくなる。
そのまま進むことになる。
