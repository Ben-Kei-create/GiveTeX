・例外とは

実行時に発生するエラーのこと。
例外が発生すると、例外クラスのオブジェクトが自動生成される。
発生する例外の種類ごとに、クラスが生成される。

Throwableクラス（親）　
　　Error（システムが原因）
　　　　VirtualMachineError 
  OutOfMemoryError
　　Exception（プログラムが原因）
　　　　RuntimeException
  　　ArrayIndexOutOfBoundsException ・・・・
色々あるなぁ。

・例外処理（try-catch）

例外発生時に自動生成される例外オブジェクトを受け取るために、
try-catchブロックをかく

try{
　　[通常の処理]
} catch(例外クラス　オブジェクト名){
 [例外発生時の処理]
}　　finally {
 [後処理]
}
public class Divide2{
  public static void main(String[] args){
    try{
      int a = Integer.parseInt(args[0]);
      int b = Integer.parseInt(args[1]);
      System.out.println("計算開始");
      System.out.println("a / b = " + (a / b) + " あまり " + (a % b));
      System.out.println("計算終了");

    }catch(ArrayIndexOutOfBoundsException e){
      System.out.println("２つの数値を入力してください");
      System.out.println("詳細：" + e.getMessage());
      e.printStackTrace();

    }catch(Exception e){
      System.out.println("例外が発生しました");
      System.out.println("詳細：" + e.getMessage());
      e.printStackTrace();

    }finally{
      System.out.println("プログラムを終了します");
    }
  }
}

例外が発生しないときは、catchをスルーする。
例外発生時には、ArrayIndexOutOfBoundsExceptionのcatchブロック処理を実行する。ただし、複数書くときには、サブクラス→スーパーから書くようにする。

public class Divide2{
  public static void main(String[] args){
    try{
      int a = Integer.parseInt(args[0]);
      int b = Integer.parseInt(args[1]);
      System.out.println("計算開始");
      System.out.println("a / b = " + (a / b) + " あまり " + (a % b));
      System.out.println("計算終了");

    }catch(ArrayIndexOutOfBoundsException e){
      System.out.println("２つの数値を入力してください");
      System.out.println("詳細：" + e.getMessage());　　//getMessageメソッドを使う。
      e.printStackTrace();　　　//printStackTraceメソッドを使う。

    }catch(Exception e){
      System.out.println("例外が発生しました");
      System.out.println("詳細：" + e.getMessage());　//getMessageメソッドを使う。
      e.printStackTrace();　　　//printStackTraceメソッドを使う。→コマンドプロンプトのエラーメッセージを表示できる。

    }finally{　　//例外あるなし関わらず「プログラムを終了します」という文字が出力される。
      System.out.println("プログラムを終了します");
    }
  }
}

import java.io.*;

public class ThrowsMethod{
  public static void main(String[] args){
    WriteFile wf = new WriteFile();
    try{
      wf.open();
      wf.write();
    }catch(IOException e){
      System.out.println("IOExceptionが発生しました");
      e.printStackTrace();
    }catch(Exception e){
      System.out.println("Exceptionが発生しました");
      e.printStackTrace();
    }finally{
      wf.close();
    }
  }
}

・回答

for文なので、繰り返し。合わせてcatchやfinalyがある。
例えば、1 2 3とコンパイルをすると、

 処理開始
　　1
 2
 3
 処理終了

となる。（正常系）
しかし、４つ目にdを代入してしまうと、NumberFormatExceptionが発生する。（処理は右から流れることに注意。）
また、

例えば、1 2 3 4とコンパイルをするとどうなるか。

>java TryDevide1 1 2 3 4

ここで生成された配列の要素数は3つしかない。
※ int[] a = new int[3]となっているため

よって

public class TryDivide2{
  public static void main(String[] args){
    try{　//例外が発生する可能性のある範囲を、try文の中に囲むことが必要。
      int a = Integer.parseInt(args[0]);
      int b = Integer.parseInt(args[1]);
      System.out.println("a / b = " + (a / b) + " あまり " + (a % b));

    }catch(NumberFormatException e){ //以下、キャッチブロックを書くことで例外に対して処理を行う。
      System.out.println("数値を入力してください");
      e.printStackTrace();　　//オブジェクトeをつかって、エラーの詳細を表示させるようにする。
    }catch(ArithmeticException e){
      System.out.println("割る数は0以外を入力してください");
      e.printStackTrace();
    }catch(Exception e){
      System.out.println("例外が発生しました");
      e.printStackTrace();
    }finally{　　//例外の有無に関わらず、表示させようと考えている文。
      System.out.println("プログラムを終了します");
    }
  }
}

また、catchブロックの中には、サブクラスから書くことが必要になる。
