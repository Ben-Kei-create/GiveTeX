Javaのかきかた


- プログラムでは、命令を使って、コンピュータに動作を指示します
- System.out.println は、データを表示する命令です。この命令をメソッドと呼びます
- カッコで指定するデータを「引数」と呼びます
- 表示する文字データをダブルクォーテーションで囲みます
- コードの行末に「;」か「}」

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello world");
    }
}

↑これで、「Hello world」と出力されます。

Javaでは、この「println」のような命令を「メソッド」と呼んでいます。

プログラミングでは、「println」のようなメソッドで、コンピュータに対して動作を指示していきます。「println」と書くと、文字を表示するのだなとJavaが理解して、そのとおり動いてくれるのです。

HTMLで表示する場合は、
printlnの中の文字の両端に、H1タグなどを入れることでOKです！

Javaのまちがい

以下のコードは、Systemの部分のSが小文字になっています。
このままでは、正しい処理ができません。

public class Main {
    public static void main(String[] args) {
        system.out.println("Hello world");
    }
}

このまま、コンパイル（読み込み、翻訳）を実行すると、このようなエラーが出てくることになります。

Main.java:3: error: package system does not exist
        system.out.println("Hello world");
              ^
1 error

無理やりコンパイルをすると、エラーがどこで出ているのかを教えてくれま
す。

-末尾のセミコロン忘れ。
- カッコやダブルクォーテーションが全角文字になっている。
- メソッドが、全て半角小文字で記述されていない。（× Println、　○ println）
- ただし、System.outの先頭は、大文字にする。
- 間違いがあるとエラーになる
- 実行時エラータブに、エラーメッセージが表示される

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello world");    // X
        System.out.println("Hello world");    // o
    }
}

コメントをのこす

コメントを使うと、コードのなかにメモを残したり、コードの一部を一時的に無効にしたりできます。コメントは、そのコードを人間が読んだ時に、わかりやすく説明をすることができるので、よく使います。

/* Javaで練習
    ここまでコメント */
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello world");   // 表示する
        // System.out.println("Hello world");
    }
}

数値と、文字列

クォーテーションなしで式を記述すると、計算結果を求めることができます。

public class Main {
    public static void main(String[] args) {
        System.out.println(100 + 30);
    }
}

ダブルクオーテーションなしでprintlnをすると、130という答えが出力されます。この時の100や30は、数値として扱います。

逆に、

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello world");
        System.out.println("100" + "30");

    }
}

このように打つと、
10030という答えが出力されます。この場合は、数字として扱われます。
数字や、文字の場合は文字列とも呼ばれます。

数値でけいさん

掛け算は、「アスタリスク」を使って、割り算には、「スラッシュ」を使います。

+：足し算
-：引き算
*：掛け算
/：割り算

このような記号を、演算子と呼びます。

式は、複数の演算子を使うことができます。複数の演算子がある場合は、左から順番に計算していきます。

public class Main {
    public static void main(String[] args) {
        System.out.println(100 + 30 + 2);    // 132と出力されます。
    }
}

変数に、データを入れる

プログラムで「変数」にデータを入れてみます。
変数は、データを入れておく入れ物で、
データを入れて、何度も使うことができます。

- 変数：データの入れ物
- 変数名：入れ物の名前
- 変数名でデータを操作できる
- Java では、データ型(データの種類)ごとに変数を定義する

変数を使うとき、最初にデータの種類を指定して宣言する必要があります。

String player = "勇者"; // 文字列データの変数
int number = 3; // 整数データの変数

Stringの頭文字は大文字にします。intは、すべて小文字です。
2回目以降、変数にデータを代入する時には、データの種類の指定は不要です。

public class Main {
    public static void main(String[] args) {
        String greeting = "Hello world";
        System.out.println(greeting);    // Hello world

        int number = 30;
        System.out.println(number);
    }
}

- 1 文字目 ：アルファベット、アンダーバー
- 2 文字目以降 ：アルファベット、アンダーバー、数字
- 大文字と小文字を区別する
- println などの命令をあらわすキーワードは使用できない

- 慣習として、日本語(全角)で書かない
- まずは、すべて小文字で変数名を付けよう

また、Javaは、予約語(キーワード)と呼ばれる単語が決まっており、この予約語は変数名に利用できません。
例えば、「public」や「class」といった単語が予約語になっています。
- Javaの予約語(キーワード)
https://ja.wikipedia.org/wiki/%E3%82%AD%E3%83%BC%E3%83%AF%E3%83%BC%E3%83%89_%28Java%29

- 整数： 1, 2, 3, 10

- byte： 8ビット整数　-128から127までの整数
- short： 16ビット整数　-32768から32767
- int： 32ビット整数　-2147483648 から2147483647
- long：　64ビット整数　-9223372036854775808から9223372036854775807まで

- 実数： 3.3, 3.141592 Float
- float：32ビット単精度小数点
- double：64ビット倍精度小数点

文字列・数値が一致しているか判定する関係演算子

==  等しい。代入と区別する    a == b

!=  等しくない  a != b
数値を大小を判定するる関係演算子

> 大なり    a > b   aはbより大きい。範囲にbを含まない
< 小なり    a < b   aはbより小さい。範囲にbを含まない
>= 以上     a >= b  aはb以上。範囲にbを含める
<= 以下     a <= b  aはb以下。範囲にbを含める

18歳より大きい：    18歳は含まれない
18歳以上：    18歳も含まれる

複数のデータをうけとる

ループ処理で Scanner オブジェクトを使うと、標準入力から複数のデータを受け取ることができます。

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);
        int count = scan.nextInt();
        System.out.println(count);

        for (int i = 0; i < count; i++) {
            System.out.println("Hello paiza");
        }
    }
}

複数のデータをわける

for と if を組み合わせると、複数のデータに同じ処理を繰り返すことができます。

import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);
        int count = scan.nextInt();

        for (int i = 0; i < count; i++) {
            int number = scan.nextInt();
            System.out.println(number);
        }
      }
}
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner scan = new Scanner(System.in);
        int count = scan.nextInt();

        for (int i = 0; i < count; i++) {
            int number = scan.nextInt();
            System.out.println(number);

            if (number == 10) {
                System.out.println(number + "は10に等しい");
            } else if (number > 10) {
                System.out.println(number + "は10より大きい");
            } else {
                System.out.println(number + "は10未満");
            }
        }
    }
}

最後のプログラムを動かしてみよう

最後のコードは、for と if を組み合わせた、編１の集大成のようなプログラムです。動きを追ってみましょう。
まず、最初に数字をひとつ受け取ります。これが「何回くり返すか」の回数（count）です。つぎに、for 文で count 回だけくり返し、そのたびに数字をひとつ受け取って、10 と比べています。
たとえば、最初に「3」と入力して、つぎに「5」「10」「20」と入力すると、こんなふうに出力されます。

5
5は10未満
10
10は10に等しい
20
20は10より大きい

「入力を受け取る → 条件で分ける → 結果を表示する」という流れが、ひとつのプログラムになりました。ここまで来れば、もう立派なプログラムを書けています。

読みながら気をつけたい小さなポイント

編１を読み返して、つまずきやすいところを3つだけ補足しておきます。
ひとつめ。「文字列をうけとる」の見出しのコードは、じつは整数を受け取る nextInt() の例になっています。文字列を受け取るときは、のちの「文字列が合っているか判別」で使われている scan.next() や、1行まるごと受け取る scan.nextLine() を使います。数字を扱うか、文字を扱うかで、使うメソッドが変わるのですね。
ふたつめ。「"100" + "30"」が「10030」になるのは、ダブルクォーテーションで囲まれたものは、数字に見えても文字列として扱われるからです。計算ではなく、文字どうしがつながっている、と考えるとわかりやすいです。
みっつめ。関係演算子のところの「判定するる」は「判定する」のことです。読み替えていただければと思います。

編１のまとめ

編１で学んだことを、振り返ってみましょう。

  • println で文字や計算結果を表示する

  • 変数という「箱」にデータを入れて、何度も使う

  • byte・short・int・long、float・double など、データの種類（型）を使い分ける

  • Scanner でキーボードから入力を受け取る

  • if・else if・else で条件によって処理を分ける

  • for で同じ処理をくり返す

  • for と if を組み合わせて、複数のデータをまとめて処理する

出力・変数・入力・条件分岐・繰り返し。この5つがそろえば、占いのプログラムや数あてのゲームのような、小さなアプリの土台はもう作れます。
