▶️Objectクラス（java.lang）

・全てのクラスのルート（大元）となるクラス
→全てのJavaのクラスは、このクラスを継承していると言える。
→オリジナルのクラスも、記述をしていなくても継承している。
class Student {

}
といれたとしても、
class Student extends Object {

}
となる。
・booklean equals(Object obj)
  自オブジェクトとobjが等しいかを比べる。
stu1.equal(stu2) → false
・String to String()
 オブジェクトの情報を文字列で返す。System.out.orintln(Obj)としたとき、
自動的にto Stringメソッドが呼び出される。

public class Student{ //自動的にObjectクラスを継承する。
  private String name;　
  
  public Student(String name){　　//名前を設定できるコンストラクタ
    this.name = name;
  }
  public String toString(){　　
    return "私の名前は" + name + "です";　　//呼び出しもとに返す。
  }
}

public class StuSample{
  public static void main(String[] args){
    Student stu1 = new Student("菅原");
    Student stu2 = new Student("菅原");

    boolean result = stu1.equals(stu2);
    System.out.println(result);
    System.out.println(stu1);　  //stu1.toString()が呼び出される。
  }
}

▶️Stringクラス（java.lang）

””で囲まれた文字列は、Stringクラスになる。
String s1 = "Java";と書いてきた。

しかし、普通は、コンストラクタを呼び出すので、
String s2 = new String("Java");
と書かなければならないはず。

・"〜"を使うと同じ文字列のオブジェクトが再利用される。
・boolean equals(Object Obj)
自文字列とObjの文字内容を比べる。
文字列の比較はequals（）を使う。
s1.equals(s2)→ true s1 == s2 → false
s1.equals(s2)→ true s1 == s3 → true

public class StringSample{
  public static void main(String[] args){
    String s1 = "Java";
    String s2 = new String("Java");
    String s3 = "Java";

    System.out.println("s1.equals(s2)：" + s1.equals(s2));
    System.out.println("s1.equals(s3)：" + s1.equals(s3));
    System.out.println("s1 == s2：" + (s1 == s2));
    System.out.println("s1 == s3：" + (s1 == s3));

    System.out.println("s1.length()：" + s1.length());
    System.out.println("s1.substring(1)：" + s1.substring(1));
    System.out.println("s1.substring(1,3)：" + s1.substring(1,3));
  }
}

・""で囲んだものはString
・前に使ったものを再利用する。
・文字列の比較をするときには、==を使わず、equals()メソッドを使う。

▶️Integerクラス

・static final int MIN_VALUE
 　　　　　　　MAX_VALUE
int型で扱える最小値〜最大値まで。

・static int parseInt(String s)
sをint型に変換する。
他にも、parsexxxxxメソッドはある。

・static String toString(int i)
iを文字列型に変換する
String s = Integer.toString(10);

public class IntegerSample{
  public static void main(String[] args){
    try{
      int i = Integer.parseInt(args[0]);
      String s = Integer.toBinaryString(i);  //10進数を2進数へと変換できる。
      System.out.println("２進数に変換：" + s);
    } catch (NumberFormatException e) {
      System.out.print(Integer.MIN_VALUE);
      System.out.print("から");
      System.out.print(Integer.MAX_VALUE);
      System.out.println("までの数値を入力してください");      
    }
  }
}

▶️Array List(E)クラス（java.util）

・インポートできる便利なクラス。
・複数のオブジェクトをまとめて管理できるコレクションクラスの一つ。
・サイズが動的に変わる配列。
・格納する要素のデータ型を<>（ジェネリックス）内に指定。
<E> のEはElements

ArrayList<String> list = new ArrayList<String>();

・boolean add (E obj)　objを最後に追加
E get(int i)   i番目の要素を取得
int size(): リストの要素数を取得
Interator<E> iterator() イテレータを取得

import java.util.ArrayList;　　　//インポートをしてあげる。

public class ArrayListSample{
  public static void main(String[] args){
    ArrayList<String> list = new ArrayList<String>();　　//ジェネリックス（どんなデータ型かを指定。）
    list.add("Java入門講座");　　//addメソッドで、３つの文字列を格納している。
    list.add("ここまで");
    list.add("よく頑張りましたね！");
    
    for(int i = 0; i < list.size(); i++){　　//list.size()には、３つの要素なので、３だと考える。
      System.out.println(list.get(i)); 　//それぞれを列挙する。
    }
  }
}

▶️イテレータとは

Iterator<E>インターフェース
コレクション内の要素を指し示すカーソルなどのようなもの
コレクションクラスのiterator()メソッドで取得できる。
・boolean hasNext() 次に要素があればtrue
・E next() 次の要素を返して、カーソルを次に移動してくれる。
・void remove(); 最後に返した要素を削除する

カーソルを移動させるようにして、探索や削除をすることができる。

import java.util.ArrayList;
import java.util.Iterator;

public class IteratorSample{
  public static void main(String[] args){
    ArrayList<String> list = new ArrayList<String>();
    list.add("これからも");
    list.add("Javaの勉強を");
    list.add("楽しんでいきましょう！");

    Iterator<String> it = list.iterator();
    while(it.hasNext()){
      System.out.println(it.next());
    }
  }
}
