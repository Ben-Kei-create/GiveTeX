AIとやってみたツール設定ファイルコマンド

GeminiCLIでできること！超オススメ

2025.07.06

Gemini CLI 親しみしかない！

こんにちは！このガイドでは、Googleが作ったすごいツール「Gemini CLI」について、わかりやすく説明していきますね。

Gemini CLI = とにかくすんごい

Gemini CLIは、コマンドラインから直接AIの力を使えるオープンソースのツールなんです。普通のチャットボットとは違って、ファイルを読んだり、コマンドを実行したり、ウェブ検索まで！開発者の皆さんのお仕事を楽にしてくれる、とっても便利な相棒です。

今回はパッと見でなにをやってくれるのか〜Gemini CLIの導入〜実際の使用法まで簡単に解説してます！

どうぞ！

Gemini CLI がやってくれること

Gemini CLIが私たちにやってくれることはたくさんありますが、たとえば

  • 長い文章を3行で要約して！　　　　　　　　　　　　　　　　　　　　→Web会議の議事録や、長いニュース記事を貼り付けて「要約して」と頼むだけで、瞬時にポイントをまとめてくれます。

  • 丁寧なビジネスメールを考えて！　　　　　　　　　　　　　　　　　　→「〇〇社への納期延長のお詫びメールを書いて」と頼めば、丁寧で適切なメール文案をすぐに作ってくれます。もうメール作成で悩む必要はありません。

  • ブログ記事やプレゼンの構成案を出して！　　　　　　　　　　　　　　→「Geminiの便利な使い方についてのブログ記事の構成案を5つ挙げて」のように、アイデア出しの壁打ち相手になってくれます。

  • 文章の誤字脱字をチェック！　　　　　　　　　　　　　　　　　　　　→作成した文章を貼り付けて「この文章を校正して」と頼めば、プロの編集者のようにチェックしてくれます。

　でも、それだと今までのAIと同じじゃ・・・

それが、実は全く違うんです！
これらの「文章を作る」「質問に答える」「コードを書く」といった機能だけを見ると、Webブラウザで使うChatGPTやGeminiのWeb版と「できること」は同じに見えるかと思います。

　すべてフローにできるところが凄さ

例をみれば一目瞭然です。

例えば、あなたがプログラミングをしていて、エラーが出たとします。

  1. プログラミング画面（エディタ）から手を離す

  2. マウスに持ち替え、Webブラウザを開く

  3. AIのサイト（ChatGPTなど）にアクセスし、ログインする

  4. エラーメッセージをコピーする

  5. ブラウザに切り替え、質問欄にペーストして質問する

  6. 回答が表示される

  7. 回答をコピーする

  8. プログラミング画面に切り替え、ペーストして修正する

Gemini CLIだと、こう変わります！

同じく、プログラミング中にエラーが出た場面です。

  1. 今いる黒い画面（ターミナル）で、そのままキーボードを打ちます。 gemini "このエラーを直して: [エラーメッセージを貼り付け]"

  2. 同じ画面に、すぐに回答が表示されます。

  3. その回答を見ながら、すぐにコードの修正作業に戻れます。

この「画面の切り替え」と「コピー＆ペースト」の繰り返しが、集中力を細かく途切れさせ、地味に時間を奪っていきます。思考の勢いが止まってしまう感覚、ありませんか？

Gemini CLIの本当のすごさは、
「AIをどこで、どのように使うか」という体験そのものが全く違う点にあります。

まずは始めてみよう！

Gemini CLIって何？

🔗 リンク：https://github.com/google-gemini/gemini-cli?tab=readme-ov-file

簡単に言うと、ターミナルで使えるAIアシスタントです。ただの質問応答じゃなくて、実際にファイルを触ったり、コマンドを実行したりできるんですよ。Googleの最新AI「Gemini 2.5 Pro」を使っていて、なんと100万トークンものコンテキストを理解できるんです。すごいでしょ？

インストールしてみよう

まず、Node.jsのバージョン18以上が必要です。入っていない方は先にインストールしてください。

🔗 リンク：https://nodejs.org/en/download

準備ができたら、こんな感じでインストールできます：

npm install -g @google/gemini-cli

「とりあえず試してみたい」という方は、こちらでもOKです：

npx https://github.com/google-gemini/gemini-cli

初回起動と認証

インストールが終わったら、ターミナルで gemini と入力して起動してみましょう。

# まさかのこれだけでOKです。。。
gemini

初回起動時には、テーマを選んだり、認証が必要になります。「Login with Google」を選ぶと、個人のGoogleアカウントでログインできて、無料枠が使えるようになります。もっと本格的に使いたい場合は、Google AI StudioやVertex AIのAPIキーも使えますよ。

APIキーは絶対に漏洩しないようにしましょう。

使い方は2パターン

対話モード（おしゃべりモード） gemini と入力すると、プロンプト（>）が表示されて、AIと自然にお話できます。終了するときは /quit か /exit と入力してください。

非対話モード（一発実行モード） --prompt（または -p）オプションを使って、一回だけ質問や命令を実行できます。 例：gemini --prompt "1から10までの素数を教えて"

コマンドをマスターしよう

Gemini CLIには3種類のコマンドがあります。覚えるのは大変そうですが、使っていくうちに慣れますよ！

1. 起動時のオプション

gemini --help で確認できる基本的なオプションです：
geminiに、howtoを聞くことでももちろん大丈夫です。

  • --model <モデル名> (-m)：使うGeminiモデルを指定

  • --prompt <プロンプト> (-p)：一発実行モード用

  • --all-files (-a)：今いるディレクトリの全ファイルを読み込み

  • --sandbox (-s)：Dockerで安全にツールを実行

  • --yolo：確認なしで自動実行（サンドボックス推奨）

  • --checkpointing：ファイルの状態を保存して、後で復元可能に

2. 対話モード中のスラッシュコマンド（/）

対話中に使える便利なコマンドです：

  • /help または /?：使えるコマンドの一覧表示

  • /quit または /exit：Gemini CLIを終了

  • /clear：画面をクリア

  • /chat：会話の保存・復元・履歴管理

  • /memory：AIの記憶（GEMINI.mdファイル）を管理

  • /tools：使えるツールの一覧表示

  • /mcp：接続されているMCPサーバーの確認

  • /restore：チェックポイント機能で元の状態に戻す

  • /compress：会話履歴を要約してトークンを節約

  • /stats：現在のセッションの統計情報を表示

3. プロンプト内の特殊な接頭辞（頭につけるもの）

これが結構面白く、ハック的な要素です。

@コマンド @<ファイルパス> や @<ディレクトリパス> と書くと、そのファイルやディレクトリの中身を読み込んでくれます。.gitignore も見てくれるので、node_modules みたいな不要なファイルは自動で除外してくれるんです。便利ですよね！

!コマンド !<シェルコマンド> でシェルコマンドを直接実行できます。! だけ入力すると、シェルモードのオン/オフを切り替えられます。シェルモード中は、入力したことが全部シェルコマンドとして実行されるので注意してくださいね。

設定ファイルでカスタマイズ

settings.json

Gemini CLIの動作は settings.json ファイルで細かく設定できます。グローバル設定（~/.gemini/settings.json）とプロジェクト設定（プロジェクトルート/.gemini/settings.json）があって、プロジェクト設定の方が優先されます。

主な設定項目：

  • theme：見た目のテーマ

  • contextFileName：GEMINI.mdの代わりに使うファイル名

  • fileFiltering：@コマンドの動作制御

  • autoAccept：ツール実行確認をスキップ

  • sandbox：サンドボックス使用

  • checkpointing：チェックポイント機能

  • preferredEditor：お気に入りのエディター

  • coreTools/excludeTools：組み込みツールの設定

仕組みを理解しよう

AIがどうやって「行動」するの？

Gemini CLIは「Reason and Act (ReAct) ループ」という仕組みを使っています。これは、AIがあなたのリクエストを分析して（Reason）、必要なツールを実行し（Act）、結果を見て計画を調整する（Observe）というサイクルを繰り返すことで、「行動」を実現しているんです。

プロンプトの構成

AIに渡される情報は、こんな感じで構成されています：

  1. システムプロンプト（GEMINI.mdの内容）

  2. ツールの定義（使えるツールの説明）

  3. 会話履歴（過去のやり取り）

  4. あなたの最新プロンプト（@コマンドで指定したファイル内容も含む）

拡張性とカスタマイズ

オープンソースなので、みんなでコードを改善したり、新機能を提案したりできます。toolDiscoveryCommand を settings.json に設定すれば、自分だけのカスタムツールも追加できるんです。可能性は無限大ですね！

データの取り扱いについて

ここは結構重要なところです。データの扱いは、どうやって認証するかで変わってきます。

無料利用枠の場合

個人のGoogleアカウントでログインしたり、無料のGemini API Keyを使った場合、あなたのプロンプトや回答は、Googleのサービス改善やモデル改善に使われる可能性があります。

有料版の場合

有料版のGemini API Key、Google Workspaceアカウント、Vertex AI経由での利用の場合は、データは保護され、サービス改善には使われません。

機密性の高い情報を扱う場合は、有料版を使うことをお勧めします。

  6. GEMINI.mdファイルの役割と、階層的な設定の仕組みは？

  7. ! コマンドの2つの使い方の違いは？

答えあわせ

  1. Gemini CLIの特徴: コマンドラインから直接GoogleのGeminiモデルを使えるツールで、開発者のワークフローを加速させます。普通のチャットボットと違って、ファイルシステムへのアクセスやシェルコマンドの実行ができるのが大きな特徴です。

  2. インストール要件: Node.jsバージョン18以上が必要です。推奨インストール方法は npm install -g @google/gemini-cli です。

  3. @コマンドの機能: 指定したファイルやディレクトリの内容をAIのコンテキストに含めてくれます。この時、.gitignoreファイルを参照して、不要なファイルは自動で除外してくれるので安心です。

  4. チャット保存機能: 現在の会話履歴を指定したタグ名で保存できます。後で /chat resume <タグ名> で復元して、複数の会話を管理できるようになります。

  5. 非対話モード: --prompt (または -p) オプションを使います。例：gemini --prompt "日本の首都は？" みたいに一発で質問できます。

  6. GEMINI.mdファイル: プロジェクト専用のシステムプロンプトを設定して、AIの「性格」やルールを定義できます。階層的に機能するので、サブディレクトリのGEMINI.mdが上位の設定を上書きしたり補完したりできます。

  7. !コマンドの使い方: ! だけだとシェルモードのオン/オフを切り替え、!<コマンド> だと指定したシェルコマンドを一回だけ実行します。

  8. 無料利用枠のデータ: プロンプトや回答がGoogleのサービス改善やモデル改善に使われる可能性があります。機密情報を扱う場合は有料版の利用がおすすめです。

  9. エージェントとしての仕組み: 「Reason and Act (ReAct) ループ」という仕組みで、リクエストを分析→計画立案→ツール実行→結果観察→計画調整のサイクルを繰り返すことで「行動」を実現しています。

  10. カスタムツールの追加: 自分で作ったスクリプトをGemini CLIのネイティブツールとして追加できるようになります。これにより、プロジェクト固有の複雑なタスクもGemini CLIで実行できるようになります。

  1. マーケティングへの応用: 開発者向けツールとして作られたGemini CLIが、マーケティング担当者の業務をどう変える可能性があるか、具体例を交えて論じてみてください。

  2. オープンソースの意義: Gemini CLIがオープンソースで無料利用枠を提供することの意味について、AI技術の普及と信頼性の観点から考えてみてください。

  3. カスタマイズ性の価値: GEMINI.mdファイルとsettings.jsonファイルが、どのようにプロジェクトへの適合性を高めるか、それぞれの役割と階層的設定の利点について説明してください。

  4. ツールとワークフロー: 「ツール」の概念と、@コマンド、!コマンド、カスタムツールが、どのようにユーザーのワークフローを効率化するか分析してみてください。

  5. プライバシーとセキュリティ: 認証方法によってデータ保護がどう変わるか、それぞれのメリット・デメリットと、機密情報を扱う際の推奨アプローチについて詳しく説明してください。

用語集

最後に、よく出てくる用語をまとめておきますね。

Gemini CLI: Googleが開発したオープンソースのコマンドラインAIエージェント。ターミナルから直接Geminiモデルを使えます。

オープンソース: ソースコードが公開されていて、誰でも自由に使ったり改良したりできること。Gemini CLIはApache 2.0ライセンスです。

AIエージェント: ただの質問応答だけじゃなく、実際にシステム上で「行動」できるAI。

コンテキストウィンドウ: AIが一度に理解できる情報の量。Gemini 2.5 Proは100万トークンという大容量です。

Node.js: サーバーサイドでJavaScriptを動かすための環境。Gemini CLIにはバージョン18以上が必要です。

ReAct ループ: AIが考えて（Reason）、行動して（Act）、結果を観察するサイクルを繰り返す仕組み。

GEMINI.md: プロジェクト専用のAI設定ファイル。AIの「性格」やルールを決められます。

サンドボックス: 安全な隔離環境でツールを実行する機能。Dockerを使います。

MCP: Model Context Protocol。外部ツールとの連携を可能にするプロトコル。

チェックポイント: ツール実行前にファイルの状態を保存して、後で元に戻せる機能。

これで基本的な使い方は理解できたと思います。あとは実際に触ってみて、自分なりの使い方を見つけてくださいね！何か分からないことがあったら、遠慮なく聞いてください。
