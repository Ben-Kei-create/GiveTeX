本日も、勉強に勤しむ。
以下は、html

<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <link rel="stylesheet" href="box.css" />
    <title>BOX</title>
  </head>

  <body>
    <!-- box1用のdiv -->
    <div class="box1">
      <div class="box2"></div>
    </div>
  </body>
</html>

こちらはcss

.box1 {
  width: 300px;
  height: 300px;
  background-color: red;
}

.box2 {
  width: 100px;
  height: 100px;
  background-color: blue;
}

このように、それぞれ２つのテキストを作らなければ、Webページは存在しえない。

    <link rel="stylesheet" href="box.css" />

これによって、cssを読み込むことができる。これを忘れてしまうと、どんなにcssで作ったとしても読み込まれることはない。

・ボックスモデル

CSSを利用すると、ボックスの幅や高さ、余白を設定できます。コンテンツ領域の周囲は、

  • 内側余白（padding）

  • 枠線（border）

  • 外側余白（margin）

で表せる！よし、取り合えず一回、サイトを作ってみよう！

続きを書いてみる。

外側の赤い箱が300×300、中の青い箱が100×100。HTMLで箱の入れ子を作って、CSSで色と大きさを決める。それだけで画面に「箱」が出てくる。Webページって、突き詰めればこの箱の組み合わせなんだな、とこの日は思った。

ボックスモデルも、並べるとすっと頭に入る。内側から順に、コンテンツ（中身）→内側余白（padding）→枠線（border）→外側余白（margin）。「幅や高さを決める」だけじゃなくて、余白をどこに取るかで見た目がまるで変わる。ここを意識できるかどうかが、きれいなページとごちゃごちゃしたページの分かれ目なんだろう。

もうひとつ、忘れちゃいけないのがCSSの読み込み。headの中に link rel="stylesheet" href="box.css" を書いておかないと、せっかく作ったCSSがページに届かない。書いたはずなのに色がつかないときは、まずこの1行を疑う。地味だけど、いちばん効くチェックポイントだ。

次は、この箱をもう少し育ててみよう。数字や色を変えてみるだけでも、ページの印象はがらりと変わる。箱が作れた時点で、サイト作りはもう始まっている。今日の学びはここまで。
