♡☆♧　HTML　♢☆♤

・拡張子

前回、保存する時に後ろについている、
「.html」は、拡張子と呼ばれるものです。これをおしり（ファイルの末尾）につけてctrl + sをすることで、HTMLファイルが作成できるそうです。
ルールとしては、最初に「|.《ピリオド》」をつける必要があります。
.hml以外にも、画像ファイルの.jpgや.png、Wordファイルの.docxなどがあるそうです。

<!DOCTYPE html>
<html lang="ja">
  <head>
    <meta charset="UTF-8" />
    <link rel="stylesheet" href="box.css" />
    <title>BOX</title>
  </head>
  <body>
    <div class="box1">
      <div class="box2"></div>
    </div>
  </body>
</html>

これは、ソースコードと呼ばれます。前にも、台本（スクリプト）の話をしたかと思います。このルールについて、学んだことを書きます。

・インデント

このソースコードをよくみると、行間や空白があります。これは、普通よりも右にずれているということです。通常よりも右にずれた位置から始めること＝インデントというのだそうです。
タグの構造がわかりやすくなり、コードが読みやすくなります。
整理整頓しながら台本が書けると、後で見返したときに楽なのだと思います。

・要素

ソースコードをよくみると、<>で囲まれたものがとても多いことがわかります。これは、タグと呼ばれるものです。タグには、

  • 開始タグ：表示内容の始まりを示すタグ　例：<div>

  • 終了タグ：表示内容の終わりを示すタグ　例：</div>

という２種類があるようです。そして、この間に入っている言葉などが、
コンテンツと呼ばれるものになります。例：<h1>ベンキョウ</h1>でいう、"ベンキョウ"の部分になります。
そして、この開始タグと終了タグ、コンテンツの３つを含めたものを、
要素と呼びます。

つまり、htmlは、「要素たちの集まり！」と考えれば、良いのかもしれません。
では、いよいよ、ソースコードを読み解いていきます。

・コメント

ショートカットキーとして、このようなソースコードを書くときに、メモをつけたいとき、ctrl + / が使えます。
これを使うと、忘れがちなタグに、メモを追加することができるようです。
例えば、

<head>
<meta charset="UTF-8" /> <!-- 文字化けを防ぐ！ -->
<title>　　ベンキョウ　　</title>

<!-- 文字化けを防ぐ！ -->と書いてありますが、これは、実際には画面には表示されないようです。なるほど、人間に優しいのね。
これを、コメントと言うそうです。
