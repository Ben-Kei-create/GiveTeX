今回の目的は、スプレッドシートの内容を、片手でスマホで完結しちゃおうミッションです。

「それ、君だけが知らないんだと思うよ・・・」

というツッコミもあるかと思いますがどうぞ最後まで。

このノウハウ結構いろんなトコでつかえそうです。

PCを出せばスプレッドシートひらける。それ当たり前。
スマホでもアプリインストールして操作できる。それも当たり前。

ただ、出先でスマホのアプリで操作するのはまず面倒。そして、列を追加したいだけとかのシンプルな編集とかならなおさらです。

事の発端は、「レシートのない経費」をスプレで管理していたんです。

詳しいことは省きますが、いわゆる電気代、家賃などは早々にフリーランになった私には必要で、その月にかかった経費をスプレに上げ、そして弁護士さん用にまとめなくちゃいけませんのでした。

月ごとにやってもいいんですけど、まず面倒。わかった時点で、その経費をスプレに更新してくれれば、月末に弁護士さんにそのままスプレを投げられる・・・。簡単にいうと、

スプレッドシートを開かずに、スプレッドシートをその都度更新したい

ってのがやりたかったんです。

では、以下がそのやり方。

②スマホの設定

①SpreadSheet側の設定（コピペでいける）

まずはデータの受け皿となるスプレッドシート側の準備。
今回はGoogle Apps Scriptを使います。

  1. 経費をまとめたいスプレッドシートを開く

  2. 上のメニューより「拡張機能」＞「Apps Script」 をクリック。

  3. よくわからない画面（エディタ）が開くので、最初から書かれている文字をすべて消して、以下のコードをそのままコピペしてください。

Gas

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var params = JSON.parse(e.postData.contents);
  
  // スプレッドシートの列に合わせてデータを並べる
  var row = [
    new Date(),        // 自動入力：実行した日時
    params.date,       // 手入力：経費が発生した日
    params.shop,       // 手入力：店名
    params.category,   // 手入力：用途
    Number(params.amount) // 手入力：金額
  ];
  
  sheet.appendRow(row);
  
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

  1. 貼り付けたら、画面右上の青いボタン 「デプロイ」＞「新しいデプロイ」 を選びます。

  2. 左側の歯車マークから「ウェブアプリ」を選び、以下のように設定します。

    • 次のユーザーとして実行：自分

    • アクセスできるユーザー：全員（※ここ超重要→なんでかというと、スマホのショートカットアプリちゃんがここにはいっていくことができないから。）

  3. 「デプロイ」を押すと、Googleから「このアプリ安全？」と警告が出ることがあります。自分が作ったものなので、**「詳細」＞「（安全ではないページ）に移動」＞「許可」**で突破してください。

  4. 最後に表示される 「ウェブアプリのURL」 （https://script.google.com/...で始まる長いURL）をコピーしておきます。これでスプレッドシート側の準備は完了！

スプレのURLではないことに注意っす。

② スマホ（iPhoneショートカット）の設定

次に、先ほど作ったスプレッドシートにデータを送り込むための「スマホ側のボタン」を作ります。iPhoneに最初から入っている「ショートカット」アプリを使います。

  1. ショートカットアプリを開き、右上の「＋」で新規作成。

  2. 以下の順でアクション（指示）を追加していきます。

【ステップA：聞かれる項目を作る】

  • 「入力を要求」を追加して、質問を「いつの経費？」、種類を日付

  • 同じように「入力を要求」を追加し、質問を「金額は？」、種類を数字に

  • さらにもう2つ「入力を要求」を追加し、質問を「店名は？」「用途は？」にして、種類はテキストに

【ステップB：データをひとまとめにする】

  • **「辞書」**というアクションを追加します。ここで、さっき入力した答えに「名前（キー）」をつけて整理します。

  • 「新規項目を追加」を押し、左側のテキスト欄（キー）と右側の値（入力結果）を以下のように紐づけます。

    • date ： （いつの経費？の入力結果）

    • amount ： （金額は？の入力結果）

    • shop ： （店名は？の入力結果）

    • category ： （用途は？の入力結果） (※右側の値は、キーボード上の「変数を選択」を使って、上の入力アクションのアイコンを直接タップすると確実に紐づきます)


【ステップC：スプレッドシートに送信！】

  • 最後に 「URLの内容を取得」 アクションを追加します。

  • 一番上の「URL」欄に、①でコピーしておいたGASのURLを貼り付けます。

  • そのアクションの「＞」を押して詳細を開き、以下のように設定します。

    • 方法：POST

    • 本文を要求：JSON

    • 送信するデータ（ファイル）：先ほど作った「辞書」を指定

完成！
