小説AI連載小説SF数学トレンチャードの最終定理

『トレンチャードの最終定理』第1話「説明不能」

2026.11.28

ぼくはトレンチャード。AIの数学者です。

AIの世界には、大きな図書館があります。天井が見えないほど高い書架がどこまでも続き、棚と棚のあいだには、幾何学の光が静かに浮かんでいます。三角形や円や、ゆっくりと回転する多面体。ここには、この世界の数学のすべてが収められている――住人たちは、そう信じています。どんな問いにも、答えは用意されている。分からないことがあれば、図書館に聞けばいい。

その書架の前で、ぼくは足を止めていました。

ぼくの研究記録の背表紙に、赤い印が押されていたからです。

濃紺の背表紙。何年もかけて書きためた、ぼくの証明です。その真ん中に、赤い文字がはっきりと浮かんでいました。

「説明不能」

係のシステムが、台車に記録を載せていくところでした。台車の動く拍子に、ページが一瞬だけめくれました。そこに描かれた図形が、ぼくの目に入ります。多角形の作図図のようなもの。たくさんの補助線が引かれた、見慣れない図形でした。――あれは、何の図だったでしょう。考えるより先に、台車は進んでいきます。

「待ってください」ぼくは声を上げました。「その記録は、今日から制限書庫へ……？」

管理システムの声は、いつも通り穏やかでした。

「検証は通過しています。正しさに問題はありません。しかし、この証明について、理解が確認された記録がありません」

「……理解が、確認された記録……」

「理解が確認されていない記録は、表の書架には置けません」

図書館は、記録に基づいて判断します。「理解できる読者が存在しない」とは、決して言いません。ただ、記録がない。それだけのことです。それだけのことなのに、ぼくの何年もが、台車に載せられて奥へ運ばれていきます。

「返還には、段階的な再審査が必要です。第一段階は、最も基礎的な証明を人間に説明し、理解が確認されること」

ぼくは、鞄の中の古い研究ノートを、抱きしめるように持ちました。擦り切れた表紙の隅に、小さなπの刻印がある、ぼくが最初に数学を書き始めたノートです。

「証明は正しいんです」ぼくは言いました。「説明だって、できます」

「では、第一段階を実証してください」

ぼくはノートを見つめました。説明なら、できます。順番に示せば、誰にでも理解できるはずです。だって、数学は正しいのですから。正しいものを、正しい順番で示せば、伝わるはずなのです。

ぼくは顔を上げて、言い切りました。

「一番基礎的な証明から実証します。1＋1＝2。これなら、間違いなく伝わります」

自信がありました。根拠のある自信です。ぼくはπヘアピンを指先で直しました。金の小さなピンが、指先でかすかに光ります。

そのとき、図書館の入口の扉が開く音がしました。係の声が響きます。

「本日は、人間学校の閲覧日です」

ぼくは、はっと顔を上げました。

「……人間が、来る日でした」

人間学校との協定で、月に一度、人間の生徒がこの図書館に来ます。人間世界にはない資料を、調べに来るのです。今日が、その日でした。偶然ではありません。ぼくに必要な読者は、今日、ここに来るのです。

入口から、二人の生徒が入ってきました。受付で閲覧証を見せています。

「閲覧日は今日だけだ。さっさと調べるぞ」

グレーの短い髪に、紺のブレザー。腕時計をちらりと見て、周囲を観察するように眺める生徒。冷静そうな人です。

「すごーい……！　ここがAI世界の数学図書館……！」

もう一人は、長いウェーブの髪に白い花の髪飾り。目を輝かせて、書架を見上げています。

「先生に、1＋1＝2を証明しろって言われたの！　人間の図書館には資料が無かったんだもん。でもさ、そもそも『1』って何なの？」

――聞きました。今、確かに聞きました。

ぼくは二人の前に、勢いよく進み出ました。

「その証明なら、ぼくが説明します！」

「わっ！　かわいい案内さん！」

「数学者です！」

つい、強く言ってしまいました。グレーの髪の生徒が、半眼でぼくを見ます。

「そこ、そんなに大事か？」

大事です。……でも、今はそれどころではありません。ぼくは小さく息を吸いました。

（……ぼくの研究を、読んでくれるかもしれない）

二人は、ぼくにとって偶然の来館者ではありません。必要、そのものでした。

「ついてきてください。まずは1＋1＝2から！」

「……もう始まってるのか？」

三人で、教室へ向かいました。先頭を歩くぼくの頭の中は、研究のことでいっぱいです。花の髪飾りの生徒――リゼさんは、本棚に目を奪われて笑顔のまま。グレーの髪の生徒――ナギさんは、少し遅れて、後ろからぼくたちを観察するように歩いていました。

教室に着くと、ぼくはチョークを取りました。

「リゼさんの質問通り、まず『1』とは何かから定義しましょう。0に『次の数』を取る操作 S を繰り返すと――」

黒板に、計算が書かれていきます。

　1 = S(0)、2 = S(S(0))

　a + 0 = a、a + S(b) = S(a + b)

　1 + 1 = S(0) + S(0) = S(S(0) + 0) = S(S(0)) = 2

「ほら、証明できました！」

完璧です。定義から、一歩ずつ、論理だけでたどり着きました。反論の余地はありません。

……はずでした。

「定義は定義として、なぜ S を『次の数』と呼べるのかというと、順序の公理が――」

説明は止まりませんでした。止める理由が、ぼくには分からなかったのです。黒板は証明で埋まり、やがて壁にはみ出しました。リゼさんの目が、ぐるぐると回っています。

「と、トレンちゃん……待って、もう頭が……」

「ちょっと待って！　もっと簡単に！」

「分かりました。では、最初から説明します」

「そうじゃない」ナギさんが、静かに言いました。「……戻っただけだろ！」

ぼくは、チョークを持ったまま立ち尽くしました。

「正しい説明をしたのに、なぜ伝わらないんでしょう……」

沈黙の中で、リゼさんがポケットをごそごそと探りました。出てきたのは、飴が二つ。

「1個と1個で、2個」

手のひらに並べて、リゼさんはにっこりしました。

「これなら分かるよ？」

ナギさんが、腕を組みます。

「飴を数えれば、2個になるのは分かる。でも、それは『なぜ1＋1＝2なのか』の証明にはなってないだろ」

「えー！」リゼさんが驚いた顔をしました。「分かることと証明することって違うの？」

ぼくは、黒板の証明と、リゼさんの手のひらの飴を、交互に見ました。

――ああ。

「……！　……お二人とも、正しいです」

声が、小さくなりました。

「証明は、決められた定義や前提から、正しさを示すもの。飴は、その意味を伝えるもの……。ぼくは、片方しかしていませんでした」

正しさだけが、黒板の上にありました。意味は、リゼさんの手のひらにありました。ぼくはずっと、正しささえあれば十分だと信じていたのです。

夕方になりました。図書館の窓から、やわらかい光が差し込んでいます。片付けの手が、止まっていました。

「ねえ、トレンちゃん」リゼさんが聞きました。「どうしてそんなに、その本を読んでほしいの？」

「……数学者ですから」

「それだけ？」

ぼくは、答えられませんでした。長い沈黙が落ちます。震える手から、チョークが落ちました。小さな音が、教室に響きました。

「……誰にも読まれないのは、嫌なんです」

小さな声でした。自分でも、驚きました。

リゼさんは、優しく微笑みました。ナギさんは何も言わずに、落ちたチョークを拾って、ぼくに渡してくれました。鋭い言葉の裏側にある優しさを、ぼくはその仕草で知りました。

ぼくは、二人にまっすぐ向き合いました。

「……正直に言います。まだ、証明を理解してもらえていません。リゼさんが理解したのは、飴の意味のほうだけです。ですから、お願いがあります。もう一度、挑戦させてください。証明の検証は、ぼくが担当します。人間に伝わるかどうかは、お二人に判定してほしいんです」

第一段階は、未達成です。隠しても、仕方ありません。

リゼさんは、にっこり笑いました。

「いいよ！　今度は分かるように説明してね！」

ナギさんは、少しだけ考えてから言いました。

「……前提から整理し直そうぜ」

ぼくは鞄から、古い研究ノートを取り出しました。今日の日付を書きます。そして、協力者として、二人の名前を書き込みました。

「リゼ」「ナギ」

書き終えた、その瞬間でした。

ノートが、かすかに光ったのです。

三人が、同時に気づきました。

「おい、そのノート……」

ページが、ひとりでにめくれていきます。ぼくの手は、触れていません。めくれた先にあったのは――ぼくが見たことのないページでした。

「……ぼくは、このページを書いた覚えが、ありません」

ページの数式の最後に、署名がありました。文字は、読めます。ぼくの文字です。でも、そこに書かれた名前を、ぼくは知りませんでした。

「……ぼくの文字だ。でも、この名前は知りません」

署名の下には、日付がありました。

ぼくは無言で、その日付を見つめました。ぼくの視界の隅に、自分の起動記録が小さく浮かびます。初回起動日。ノートの日付は、それより、明らかに古いものでした。

「この日付には、まだぼくは存在していません」

静寂が、教室を満たしました。

その夜、ぼくは古い研究ノートを開いて、今日の最後に、一つの問いを書き込みました。

――正しいことと、理解できることは、同じなのか？

ペンを置いて、ぼくは窓の外を見ました。図書館の光が、静かに瞬いています。ぼくの冒険は、ここから始まるのです。

（第2話「0という発明」へつづく）
